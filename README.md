# Sayframe

Панель для Adobe After Effects: вы описываете словами, что нужно сделать в композиции, а Claude пишет и сразу выполняет скрипт. Умеет смотреть на видео- и фото-референсы, проверять свой результат по кадрам и вставлять картинку из буфера обмена.

В панели три вкладки. Чтобы поменять их местами, дважды щёлкните по вкладке и перетащите; так же меняются местами блоки в разделе «Анимация»:

- **Claude** — задача словами, референс, запуск и ответ.
- **Инструменты** — вставка картинки из буфера обмена.
- **Анимация** — плавность выделенных ключей, перенос точки привязки в угол, к краю или в центр слоя выравнивание слоёв по композиции или друг по другу распределение слоёв через равные промежутки и сдвиг во времени: появление и исчезновение слоёв можно двигать по кадрам, подводить к указателю времени и расставлять лесенкой. Плавность меняется сразу, пока вы двигаете ползунок.

## Установка

### Mac

1. Скачайте [Install-Sayframe-Mac.zip](https://github.com/dalerodinaevb-arch/sayframe/raw/main/downloads/Install-Sayframe-Mac.zip) и дважды щёлкните по нему — появится программа «Install Sayframe».
2. Дважды щёлкните по ней и нажмите «Установить».
3. Перезапустите After Effects и откройте Window > Extensions > Sayframe.

Если macOS пишет, что не может проверить программу: нажмите «Готово», откройте Системные настройки > Конфиденциальность и безопасность, внизу нажмите «Всё равно открыть» рядом с «Install Sayframe».

**Запасной способ для Mac.** Если программа не открывается совсем, откройте «Терминал» (Программы > Утилиты), вставьте эту строку и нажмите Enter:

```
curl -fsSL https://raw.githubusercontent.com/dalerodinaevb-arch/sayframe/main/install.sh | bash
```

Она скачивает панель и ставит её так же, как установщик; предупреждений macOS при этом нет.

### Windows

1. Скачайте [Install-Sayframe-Windows.exe](https://github.com/dalerodinaevb-arch/sayframe/raw/main/downloads/Install-Sayframe-Windows.exe) и дважды щёлкните по нему.
2. Если появится синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
3. Нажмите «ОК» в окне установщика. Права администратора не нужны.
4. Перезапустите After Effects и откройте Window > Extensions > Sayframe.

Если антивирус не даёт запустить exe, есть запасной вариант: [Sayframe-Windows.zip](https://github.com/dalerodinaevb-arch/sayframe/raw/main/downloads/Sayframe-Windows.zip) — распакуйте архив целиком и запустите `Install-Windows.bat`.

### Первый запуск

- Нажмите на шестерёнку и вставьте ключ Anthropic API (создаётся на platform.claude.com, раздел Settings > API keys). Ключ хранится только на вашем компьютере.
- Включите в After Effects: Settings > Scripting & Expressions > Allow Scripts to Write Files and Access Network. Это нужно для референсов, проверки результата и вставки картинок.

## Обновления

Панель сама проверяет, вышла ли новая версия. Когда она выходит, вверху панели появляется плашка с описанием и кнопкой «Обновить». Панель скачивает новые файлы, сверяет их контрольные суммы и перезапускается. Запускать установщик заново не нужно. Проверить вручную: шестерёнка > «Проверить обновления».

## Для разработчика

| Папка | Что в ней |
| --- | --- |
| `Sayframe/` | сама панель: `index.html`, `css/`, `js/panel.js` (логика), `jsx/host.jsx` (часть, работающая внутри After Effects) |
| `installer/` | установщики: `src/` — общая программа на Go для Mac и Windows; `mac/launcher` и `windows/stub.exe` — она же в собранном виде; `mac/` — ещё значок и описание приложения |
| `install.sh` | установка на Mac одной командой в Терминале; файл создаёт `tools/release.py` |
| `downloads/` | готовые установщики, их собирает `tools/release.py` |
| `version.json` | описание последней версии; его читает панель у пользователей |
| `tools/` | `release.py` и `config.json` с адресом репозитория |
| `tests/` | проверки панели, сетевой части и установщика |

### Как выпустить обновление

1. Измените файлы в `Sayframe/`.
2. Запустите проверки: `bash tests/run.sh`.
3. Подготовьте выпуск с новым номером и описанием для пользователей:

   ```
   python3 tools/release.py 1.2.0 "Что нового, первая строка" "Вторая строка"
   ```

   Команда ставит номер версии во все файлы, пересобирает установщики и записывает `version.json`. Установщик для Windows получается так: к `installer/windows/stub.exe` приписывается архив с панелью. Установщик для Mac — приложение, внутри которого лежат `installer/mac/launcher` и папка панели. Обе программы нужно пересобирать (`bash tools/build-installers.sh`, нужен Go) только после изменений в `installer/src`.

Программа внутри приложения для Mac обязана быть настоящей программой для Apple-чипа и Intel. Приложение, у которого вместо программы скрипт, macOS на Apple-чипе без Rosetta считает несовместимым и показывает с перечёркнутым значком.
4. Отправьте всё в GitHub: `git add -A && git commit -m "Sayframe 1.2.0" && git push`.

После этого пользователи увидят плашку обновления при следующем открытии панели (проверка идёт не чаще раза в 6 часов, GitHub отдаёт новые файлы с задержкой до нескольких минут).

Правило: любое изменение в `Sayframe/`, отправленное в GitHub, должно идти вместе с новым выпуском. Иначе контрольные суммы в `version.json` перестанут совпадать с файлами и обновление у пользователей не установится. `python3 tools/release.py --check` показывает, всё ли согласовано.

### Переезд на свой сервер

1. Выложите на сервер по https файл `version.json` и рядом папку `Sayframe/` (те же, что в репозитории).
2. В `version.json` в этом репозитории впишите адрес нового файла в поле `moved`, например `"moved": "https://example.com/sayframe/version.json"`, и отправьте в GitHub.

Уже установленные панели перейдут по этому адресу и запомнят его. В новых версиях адрес по умолчанию задаётся в `tools/config.json` и в `update_url()` внутри `tools/release.py`.

### Проверки

`bash tests/run.sh` — нужны python3, node, openssl, пакет `playwright` с браузером Chromium и Go (без Go пропускается только проверка установщиков). Панель проверяется в настоящем браузере с имитацией After Effects; сам After Effects для этого не нужен. Окна установщиков, запись в реестр Windows и запуск на настоящих Mac и Windows этими проверками не выполняются.
