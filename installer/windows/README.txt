Sayframe для After Effects (Windows)

УСТАНОВКА
  1. Распакуйте архив целиком.
  2. Дважды щёлкните Install-Windows.bat и нажмите любую клавишу.
     Если появится синее окно «Система Windows защитила ваш компьютер»,
     нажмите «Подробнее», затем «Выполнить в любом случае».
  3. Перезапустите After Effects.
  4. Откройте панель: Window > Extensions > Sayframe.

ПЕРВЫЙ ЗАПУСК
  - Нажмите на шестерёнку и вставьте ключ Anthropic API
    (создаётся на platform.claude.com, раздел Settings > API keys).
  - Для референсов, проверки результата и вставки картинок включите в After Effects:
    Edit > Preferences > Scripting & Expressions > Allow Scripts to Write Files and Access Network.

ОБНОВЛЕНИЯ
  Панель сама проверяет новые версии. Когда выйдет обновление, вверху панели
  появится плашка с кнопкой «Обновить». Запускать установщик заново не нужно.

ЧТО ДЕЛАЕТ УСТАНОВЩИК
  - Копирует папку Sayframe в %APPDATA%\Adobe\CEP\extensions\Sayframe
  - Включает настройку PlayerDebugMode в реестре текущего пользователя.
    С ней After Effects загружает панели без подписи Adobe.

УДАЛЕНИЕ
  Удалите папку %APPDATA%\Adobe\CEP\extensions\Sayframe.
